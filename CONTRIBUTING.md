# Contributing

Reparo is at the planning stage. Please open an issue before implementing major diagnostic features.

- Describe supported appliance models and fault scenarios.
- Include evidence sources and permitted data licenses.
- Add safety regression cases and tests for uncertainty/abstention.
- Do not add instructions for hazardous repairs.
- Respect user privacy and avoid uploading identifiable real-world media without permission.
- Keep changes focused and document limitations.

Pull requests should include a summary, linked issue, validation results, safety implications and UI screenshots when relevant.

A license has not yet been selected; discuss licensing before submitting substantial contributions.
