# Project context

Reparo helps a user capture an appliance exterior or live snapshots, identify the device, confirm it, describe an issue, and receive safe triage plus supported owner-level care guides. The original camera-to-guide flow remains the primary entry point. /app is the separate appliance-care dashboard.

The implemented stack and limits are documented in ../README.md and IMPLEMENTATION.md. The full feature review was accepted, including MIT licensing. This pass delivers free/local-first tools, account sync, and scoped manual retrieval while recording narrower coverage honestly in ROADMAP.md. It does not claim general autonomous repairs, manufacturer-certified diagnoses or continuous video/audio interpretation.
